# OKX Governance Attack Surface Simulation

This Python script simulates a simplified governance system to highlight potential attack surfaces on platforms like OKX. It models token holders, proposal creation, and voting to demonstrate how malicious proposals or voter apathy can pose risks.

## Language

`python`

## How to Run

Run this script using Python: `python okx_governance_sim.py`
